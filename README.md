# 🌸 ARIMBI — Period Tracker

A beautiful, privacy-first period tracker PWA (Progressive Web App).

## Features

- 📊 Cycle countdown with visual progress ring
- 📅 Calendar view with period, fertile window & ovulation markers
- 😊 Daily mood & symptom tracking
- 📋 Cycle history & statistics
- 🔔 Push notification reminders
- 📱 Installable as native app (PWA)
- 🔒 100% offline — all data stored locally on device

## Tech Stack

- Vanilla HTML/CSS/JS (no frameworks, no build tools)
- Service Worker for offline support
- Web Push Notifications
- Plus Jakarta Sans typography

## Install on Phone

1. Open the URL in Chrome (Android) or Safari (iOS)
2. Android: Tap ⋮ menu → "Install app" or "Add to Home Screen"
3. iOS: Tap Share → "Add to Home Screen"

## Development

```bash
python serve.py
# Open http://localhost:8080
```

## Deploy

Push to GitHub → Connect to Vercel → Auto-deploy.

## Privacy

All data is stored in localStorage on the user's device. No data is ever sent to any server.
